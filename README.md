# @stackline/vue-multiselect-dropdown Vue 3 Playground

Dedicated StackBlitz playground for the Vue 3 line of `@stackline/vue-multiselect-dropdown`.

Each example has its own route, folder, Vue component file, data file, and CSS file. The project is intentionally small enough for StackBlitz while still keeping the examples readable.

## Run

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## StackBlitz

```text
https://stackblitz.com/github/alexandroit/stackline-vue-multiselect-vue-3?file=src%2Fexamples%2Fbasic%2Fbasic.component.vue&startScript=start&initialpath=%2Fbasic
```

## Package

```bash
npm install @stackline/vue-multiselect-dropdown@3.1.3 --save-exact
```
